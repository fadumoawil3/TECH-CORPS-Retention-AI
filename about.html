About this project

Why we built the TECH CORPS Program Retention Analysis System, and what's under the hood.

Project Overview

The TECH CORPS Program Retention Analysis System is an AI-powered web application that helps TECH CORPS staff analyze student retention data, identify engagement patterns, recognize students who may need additional support, and generate actionable recommendations for improving program outcomes.

Why We Chose This Project

Team Prompt Patrols

Our team selected this project because we participated in TECH CORPS ourselves and wanted to create a solution that improves future student experiences.
